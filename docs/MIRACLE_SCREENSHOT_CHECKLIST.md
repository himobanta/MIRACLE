## Instructions for Capturing
1. Open `https://miracle-production-e7d3.up.railway.app` in Google Chrome.
2. Use **F12 DevTools → Device Toolbar** to test responsive sizes.
3. Capture screenshots with **Windows + Shift + S** or browser screenshot tool.
4. Save to `docs/screenshots/` directory in the repository.
