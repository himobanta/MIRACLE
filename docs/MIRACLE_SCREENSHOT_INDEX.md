## Capture Instructions
1. Open Chrome and navigate to `https://miracle-production-e7d3.up.railway.app`
2. Use **Windows + Shift + S** or the Chrome screenshot extension
3. For responsive sizes: **F12 → Device Toolbar** → set viewport width
4. Save files to `docs/screenshots/` using the filenames below
5. Update this index with `[x]` when captured
